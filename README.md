# Shadow Ages: Bagel

**Shadow Ages: Bagel** — мрачный экшен с элементами roguelike, построенный вокруг искажённого библейского лора, смертных грехов и циклической боевой системы.  
Игра разрабатывается на **Unreal Engine 5** с фокусом на зрелищные сражения, простые, но цепляющие механики и нарративную деградацию главного героя.

> Мир, в котором ангелы и демоны сошли на землю, а человек оказался единственным, кто может этим воспользоваться.

---

## 🎮 Жанр

- Action / Hack & Slash  
- Roguelike (циклические волны, риск–награда)
- Dark Fantasy
- Single-player

---

## 🧠 Ключевая идея

Shadow Ages — это история **восхождения через грех**.

Игрок начинает как никому не нужный крестьянин и шаг за шагом получает силу, подчиняясь демонам смертных грехов.  
Каждая глава — это не просто новый босс, а **моральное падение**, которое отражается в механиках, способностях и мире.

---

## 📖 Сюжет (кратко, без спойлеров)

- Второе пришествие начинается.
- Ангелы и демоны спускаются на землю и теряют неуязвимость.
- Принцесса ада Мамона предлагает сделку.
- Герой проходит путь через **Жадность, Похоть, Лень, Чревоугодие, Зависть, Гордыню и Ложь**.
- Каждая победа делает его сильнее.
- Каждое решение — менее человеком.

Финал намеренно лишён «хэппи-энда».

## ⚔️ Боевая система

- **Циклические волны врагов** за пределами деревни
- Смерть сбрасывает прогресс текущего цикла
- Возрождение возможно, но за плату
- Возврат в деревню — точка апгрейда и риска

### Типы атак
- Ближний бой (оружие)
- Дальнобойная магия
- Переключение стилей в реальном времени

---

## 🔥 Пути силы

Всего в игре реализовано **7 путей**, каждый из которых открывается сюжетно:

1. **Путь Воина** — базовый физический урон
2. **Путь Уничтожения** — молнии (эффективны против демонов)
3. **Путь Разрушения** — огонь (эффективен против ангелов)
4. **Путь Ослабления** — дебаффы, контроль
5. **Путь Поглощения** — вампиризм и жертва ХП
6. **Путь Призыва** — союзные существа
7. **Путь Аннигиляции** — финальная, разрушительная сила

Каждый путь влияет на стиль игры и визуальное восприятие боя.

### Сборка после перехода на UE 5.8.2

Unreal Engine 5.6.1 для открытия и сборки не требуется. В `ShadowAges.uproject`
указана ассоциация `5.8`: номер исправления проверяется по установленному движку
(`Engine/Build/Build.version`, ожидается 5.8.2).

Используйте Visual Studio с компонентами из `.vsconfig`. Сгенерировать решение
и собрать проект можно из PowerShell в корне репозитория:

```powershell
$engine = 'C:\Program Files\Epic Games\UE_5.8'
$project = Join-Path $PWD 'ShadowAges.uproject'
& "$engine\Engine\Build\BatchFiles\Build.bat" -projectfiles "-project=$project" -game -rocket
& "$engine\Engine\Build\BatchFiles\Build.bat" ShadowAgesEditor Win64 Development "-Project=$project" -WaitMutex
& "$engine\Engine\Build\BatchFiles\Build.bat" ShadowAges Win64 Development "-Project=$project" -WaitMutex
```

Встроенные исходники Narrative 3 и FMOD 2.03.11 адаптированы к API UE 5.8.
Для FMOD нужны библиотеки версии **2.03.11** в `Plugins/FMODStudio/Binaries/Win64`:
`fmod.dll`, `fmodL.dll`, `fmodstudio.dll`, `fmodstudioL.dll` и соответствующие
`*_vc.lib`. Каталог `Binaries` исключён из Git, поэтому на новом компьютере
эти файлы нужно восстановить из пакета FMOD. При переносе использован уже
имевшийся архив `fmodstudio20311ue5.6win64.zip`: из него извлечены только
библиотеки FMOD и аудиоплагинов, а модули `UnrealEditor-*` собраны заново на 5.8.2.
Установка UE 5.6 для использования этого архива не нужна.

Исправлены и пересохранены на 5.8.2 три ассета Narrative:
`WBP_DefaultQuestNode`, `NE_CompleteNarrativeTask` и `NE_RestartQuest`.
Для события перезапуска сохранён одиночный необязательный ID: метод
`RestartQuestFromID` преобразует его в список состояний нового API,
а `None` означает обычное начало квеста.

Если локальный Zen не запускается, для проверки через командную строку можно
добавить `-ddc=InstalledNoZenLocalFallback` — это штатный файловый кэш движка.
